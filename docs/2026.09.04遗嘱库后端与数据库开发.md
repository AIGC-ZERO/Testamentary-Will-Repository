## 3. 本地启动摘要

```bash
cd will-demo/backend
docker compose up -d postgres
npm install
npx prisma migrate dev --name init
npm run prisma:seed
npm run start:dev
```

- API：`http://127.0.0.1:3000`  
- 健康检查：`GET /api/health`  
- 环境模板：`backend/.env.example`
